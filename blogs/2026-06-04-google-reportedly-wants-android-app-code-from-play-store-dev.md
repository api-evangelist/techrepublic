Google is reportedly paying select Android developers for access to their app source code through a confidential content offer pilot, with the code potentially used to improve AI products. Developers should carefully review what they are sharing, verify code ownership, check for sensitive credentials or third-party licenses, and clarify how Google will use the submitted code before signing any agreements.
