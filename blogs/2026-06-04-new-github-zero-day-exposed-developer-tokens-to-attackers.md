A zero-day vulnerability in github.dev allowed attackers to steal GitHub OAuth tokens through malicious extensions in a compromised repository. The flaw, disclosed by security researcher Ammar Askar, could enable attackers to access private repositories and push malicious code to production. Microsoft implemented mitigations on June 3, though developers can protect themselves by clearing cached data for github.dev.
